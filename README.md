# CHRONIQUE — Micro-Magazine Éditorial Interactif

Application web complète pour un micro-magazine éditorial interactif consacré à la direction artistique, au brutalisme poétique et aux univers visuels immersifs.

## 🛠️ Stack Technique
* **Framework :** React 18, Vite, TypeScript
* **Design & Typographie :** Tailwind CSS, Cormorant Garamond, Playfair Display, Plus Jakarta Sans, JetBrains Mono
* **Scrollytelling & Animations :** Lenis (smooth scroll inertiel), GSAP (ScrollTrigger)
* **Audio & Filtres :** Web Audio API (drone harmonique ambiant), filtres optiques (Cinéma, Monochrome, Plan 1:100)

## 🚀 Lancement

### Version Autonome (sans installation)
Double-cliquez directement sur `CHRONIQUE-Magazine.html` ou `Lancer-Chronique.bat`.

### Version Développement
```bash
npm install
npm run dev
```

### Build Production Autonome
```bash
npm run build
```
